# 패스포트 (익명 신원)

**패스포트**는 Quipier의 끝 사용자 신원입니다. 이메일·비밀번호 가입 없이, 사용자가 직접 만든 **익명 신원**으로 댓글을 답니다.

## 사용자 경험

1. 위젯에서 **"패스포트로 연결"** 을 누르면 `passport.quipier.com` 팝업이 열립니다.
2. 사용자는 새 패스포트를 만들거나(시드 문구 생성) 기존 패스포트로 다시 연결합니다.
3. 프로젝트에서 쓸 **닉네임**을 정하면 연결 완료 — 이후 그 사이트에서 같은 닉네임으로 작성합니다.

같은 패스포트로 다시 연결하면 이전 닉네임이 자동으로 적용됩니다.

## 신원 모델

- **마스터 신원** — 사용자의 루트 신원. 시드(복구 문구)로만 복원되며 서버에 저장되지 않습니다.
- **프로젝트 토큰** — 프로젝트마다 분리된 작성자 ID. 사이트 간 활동이 직접 연결되지 않습니다.
- **닉네임** — 프로젝트별 표시 이름.

> 시드 문구는 사용자만 가지고 있습니다. 분실하면 복구할 수 없으니, 사용자에게 백업을 안내하세요.

## 운영자가 할 수 있는 것

- **작성자 차단** — 특정 패스포트를 차단하면 IP가 바뀌어도 그 프로젝트에서 댓글을 쓸 수 없습니다.
- **IP 차단** — 댓글의 출처 IP를 차단합니다(운영자에게 IP는 마스킹되어 보입니다).

자세한 모더레이션은 [Comments 연동](/comments/)의 모더레이션 절을 참고하세요.
